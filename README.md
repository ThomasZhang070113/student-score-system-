基于 Excel 的成绩查询系统 (Student Score System Based on Excel)

一个纯前端、无需后端的本地成绩查询工具。上传 Excel 表格后，即可按学号、姓名等条件快速查询成绩，并自动统计最高分、最低分、平均分和及格率。

## ✨ 功能特性
- 📁 支持上传 `.xlsx` / `.xls` / `.csv` 文件，所有数据仅在浏览器本地解析。
- 🔍 支持关键字模糊搜索，可按学号、姓名或任意列查询。
- ➕ 支持添加多个组合条件进行精确筛选（如：数学 > 90）。
- 📊 自动统计各科最高分、最低分、平均分、中位数、及格率。
- 📥 查询结果支持一键导出为 CSV 文件。
- 💻 支持切换工作表和调整表头行，适配多种表格格式。

## 🚀 使用方法
1.1. 访问在线演示地址：[点击这里使用]https://github.com/ThomasZhang070113/student-score-system-/settings/pages
2. 点击上传区选择你的 Excel 成绩表，或直接拖拽进去。
3. 顶部可切换工作表和表头行，下方输入关键字即可查询。
4. 在统计区选择科目，查看该科目的分数统计。

## 📦 本地使用与下载
本仓库包含完整的 `index.html` 单文件源码。
1. 点击仓库右上角绿色的 **Code** 按钮，选择 **Download ZIP**。
2. 解压后双击 `index.html` 即可在本地浏览器打开使用（需联网加载解析库，建议使用 Chrome 或 Edge）。

## ⚙️ 技术栈
- HTML5 + CSS3 + 原生 JavaScript
- [SheetJS (xlsx)](https://sheetjs.com/) - 用于解析 Excel 文件
- 数据完全在浏览器端处理，不上传服务器，安全放心。
